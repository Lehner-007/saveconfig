# saveconfig 0.8.2

Einheitliche Hilfe mit F1 und Programmlogo. Acht zusätzliche Sprach- und Hilfepakete. Netzwerkziele im Profil werden vor der Sicherung geprüft; Cache- und Codex-Daten sind ausgeschlossen.

Das DEB enthält Deutsch und Englisch. Weitere Sprachen können in den Einstellungen nachgeladen werden. Zusatzübersetzungen benötigen noch eine Muttersprachlerprüfung.
